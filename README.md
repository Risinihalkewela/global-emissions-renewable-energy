# Global Emissions & Renewable Energy Adoption (2000–2021) 🌍⚡

This project examines worldwide greenhouse gas (GHG) emissions and renewable energy adoption between 2000–2021. Using **SQL Server** for data cleaning and **Power BI** for interactive dashboards, the study highlights sustainability progress, country-level comparisons, and policy impacts.

## 📊 Datasets
- Source: UN SDG Global Database
- Indicators:
  - SDG 13: CO2 emissions
  - SDG 7.2.1: Renewable energy share in total final energy consumption
- Coverage: 2000–2021
- Format: Excel → SQL tables

## ⚙️ Methodology
1. **Data Cleaning (SQL Server):**
   - Removed redundant metadata
   - Fixed data types and missing values
   - Created unified analytical views
2. **Power BI Dashboards:**
   - 3 interactive pages
   - Advanced DAX measures (YOY growth, averages, sustainability scorecards)
   - Country-level comparisons and global maps
3. **Analysis:**
   - Trends in emissions and renewable adoption
   - Correlation between RE growth and GHG reduction
   - Regional performance insights

## 🚀 Results
- Countries with higher renewable adoption show reduced emissions growth.
- Clear inverse relationship between GHG emissions and RE adoption.
- Dashboards provide policymakers and researchers with actionable insights.

## 🛠️ Tech Stack
- SQL Server (ETL, cleaning, aggregation)
- Power BI (DAX, dashboards, interactive visuals)
- UN SDG Global Database
